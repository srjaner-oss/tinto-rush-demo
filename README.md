# Tinto Rush ☕

Juego móvil hypercasual hecho en Colombia. Deslizas pocillos de tinto por la mesa de la oficina y tienes que frenarlos justo frente a cada cliente.

Una sola mecánica. Partidas de 20 a 40 segundos. Modo infinito.

## Estado

En desarrollo. Mecánica de varios clientes a la vez en prueba con testers.

## Con qué está hecho

- React Native + Expo, TypeScript
- Skia para el render del juego
- Reanimated para la física, que corre fuera del hilo de React
- Física propia y determinista: el mismo gesto da siempre el mismo resultado
